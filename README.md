# 1. OVERALL CREATIVE DIRECTION

Create a premium, futuristic, creative digital-agency portfolio website for DIGITAL MOV.

The website should feel:

- Premium

- Creative

- Futuristic

- Cinematic

- Minimal

- Elegant

- Interactive

- Technology-focused

- Motion-driven

- Professional enough for a real client

- NOT like a generic template

The website should make the visitor think:

"This company creates digital experiences."

The animations should be a major part of the identity.

However:

DO NOT overload the page with animations.

Every animation must have a purpose.

The design principle should be:

"Simple interface + impressive motion."

Avoid:

- Generic SaaS layouts

- Excessive gradients

- Random floating elements

- Excessive glassmorphism

- Overly complicated backgrounds

- Too many colors

- Cheap-looking animations

- Template-like sections
